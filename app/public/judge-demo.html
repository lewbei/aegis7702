03 / Know the boundary

A concrete loss witness.
Not a universal safety promise.

Bounded verification. The repository describes a supported action space with search depth up to three and a primary tracked ERC-20 token. No modeled loss found does not establish global safety against unsupported actions, deeper paths, or other assets.

State-specific recovery. A successful known-trace replay check is about the tested state and trace. It is not a claim that every future path is safe, that funds already lost can be recovered, or that a recovery transaction will win a live ordering race.

Research prototype. Broad error classification remains a review caveat. Unknown infrastructure outcomes must not be presented as proof of safety. This page deliberately offers no live wallet-protection service. Inspect the current classifier ↗
